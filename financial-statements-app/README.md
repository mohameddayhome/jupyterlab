# نظام إعداد القوائم المالية — مكتب المدقق

تطبيق Google Apps Script + Google Sheets بواجهة بنمط Dynamics 365.

## الملفات
- `Code.gs` — كود الخادم (Apps Script)
- `index.html` — الواجهة (ملف HTML باسم `index` في مشروع Apps Script)
- `preview/` — صور معاينة

## التثبيت
1. افتح Google Sheet جديد ← **Extensions ← Apps Script**.
2. الصق محتوى `Code.gs` في ملف `Code.gs`.
3. أنشئ ملف **HTML** باسم `index` والصق فيه محتوى `index.html`.
4. **Deploy ← New deployment ← Web app**.
5. افتح التطبيق واضغط **"إعداد قاعدة البيانات"** (المستخدم الافتراضي: `admin` / `admin123` — غيّره بعد أول دخول).

## الميزات
- دليل حسابات معياري: القوائم تُبنى تلقائياً من نوع الحساب وتصنيفه.
- ميزان مراجعة مع استيراد Excel وتنبيه تكرار السحب.
- ربط حسابات العميل بالدليل (يدوي وتلقائي).
- الميزانية العمومية، قائمة الدخل، التدفقات النقدية وفق IAS 7 (غير مباشرة + مباشرة).
- ورقة عمل لمراجعة الأرصدة المكوّنة لكل بند.
- المرفقات (الإيضاحات المتممة): إيضاح مرقّم لكل بند مع أرقام المقارنة، وطباعة القوائم مع المرفقات في تقرير واحد.
- تصدير Excel من كل صفحات التطبيق، وملف Excel شامل (7 أوراق) لكل عميل وسنة.
- مؤشرات الأداء ومقارنة السنوات، مع طباعة وتصدير Excel.
- جلسات دخول آمنة على الخادم مع انتهاء بعد 30 دقيقة خمول.
